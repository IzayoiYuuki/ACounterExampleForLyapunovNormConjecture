# A counter example for Lyapunov norm conjecture

## Authors

Weiguo Gao, Feiyang Jiang, Yuqi Liu

## Overview

We found a 7x7 counterexample to the Lyapunov conjecture with the assistance of large language models.
We also investigated the 6x6 case and derived a sufficient condition for the existence of a counterexample.

## Contents

- `note.pdf` documents our latest progress and results.
- `test_Lya.m` contains a 7x7 integer counterexample to the Lyapunov conjecture, together with MATLAB verifying code.
- `history/` contains selected valuable results from our previous discussions with large language models.
